# cassandra-5-movie-search

Companion code for a ten-week developer series on Apache Cassandra® 5.0:
[Storage-Attached Indexing
(SAI)](https://cassandra.apache.org/doc/5.0/cassandra/developing/cql/indexing/sai/sai-overview.html)
and [vector
search](https://cassandra.apache.org/doc/5.0/cassandra/vector-search/overview.html),
taught by building movie search for a fictional app called cMovie.

The series publishes on [8567.me](https://8567.me), starting with the [series
overview](https://8567.me/posts/c5-cmovie-overview/). This repo holds the data
loader and the application code each week builds on.

## Setup

Start with the [setup page](docs/setup.md). It covers creating an [Astra
DB](https://www.ibm.com/products/datastax?utm_medium=social&utm_campaign=ai-db-scale&utm_content=erickramirez)
database, generating a token, downloading the secure connect bundle, getting a
Google AI Studio key and running the loader.

## Repository layout

| Path | What it holds |
| --- | --- |
| `docs/setup.md` | The reader setup page, linked from every post |
| `tools/` | The data loader (`loader.py`), the Wikidata and Wikipedia module it imports, and `connection.py`, the database connection shared by the loader and the tutorial apps. Run the loader from the repo root as `python tools/loader.py` |
| `tutorials/week-NN/` | Each week's CQL files and a short README, plus the week's application code from week 2 (`app.py`) |
| `.env.example`, `requirements.txt` | Shared by every week. `requirements.txt` covers the loader and the tutorial apps. Your own `.env` and the secure connect bundle also live in the repo root |

## What the series teaches

The series teaches only capabilities present in Cassandra 5.0. The examples
run on Astra DB because that keeps the setup out of the way, but Astra DB is the
runtime, not the syllabus. Anything taught here also runs on Cassandra 5.0.

The series doesn't cover administration, so there's no keyspace creation,
replication strategy or node operations. The audience is building an
application, not running a database.

## Data

Movie facts such as title, release year, genres and runtime come from
[Wikidata](https://www.wikidata.org), released under [CC0
1.0](https://creativecommons.org/publicdomain/zero/1.0/). Plot text and the
starring actors come from the [English Wikipedia](https://en.wikipedia.org),
released under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).
Any reuse of that text carries the same licence and needs attribution back to
the source article.

cMovie's own rating, vote count and popularity figures are generated by the
loader. They are fictional in-app numbers, not real audience scores from any
source.
