# Week 6: a movie assistant with Cassandra and Gemini

Companion files for the
[week 6 post](https://8567.me/posts/c5-cmovie-wk06-rag-movie-assistant/) of the
cMovie series on [8567.me](https://8567.me). The series teaches Apache
Cassandra® 5.0 features by building movie search for a fictional app called
cMovie, running on Astra DB.

This week you add `GET /movies/assist` to the cMovie API. It finds the movies
closest in meaning to a request, with the filtered `ANN OF` query from week 5,
then asks Gemini to recommend from those movies and nothing else. There is no
schema change and no new index this week, so there's no `schema.cql`.

## Files

| File | What it is |
| --- | --- |
| [`queries.cql`](queries.cql) | The CQL the endpoint runs, with and without filters, and a filter that matches nothing |
| [`app/main.py`](../../app/main.py) | The API. `/movies/assist` is the new endpoint |
| [`tools/llm.py`](../../tools/llm.py) | The new helper that calls Gemini's `generateContent` endpoint |

`queries.cql` is a reference copy to paste into the Astra CQL console, one
statement at a time. It isn't a script to run as a whole, and it doesn't create
a keyspace. Run `USE default_keyspace;` first, as the post explains.

## What you need

- The `movies` table from weeks 1 to 3, with every movie's `plot_embedding`
  filled in, the vector index from week 3's
  [`schema.cql`](../week-03/schema.cql) built and the `wikipedia_url` column
  filled in by the loader.
- `GEMINI_API_KEY` in your `.env` file. The setup page covers it in
  [section 3](../../docs/setup.md#3-google-ai-studio).

From the root of the repo, in your virtual environment, start the API:

```bash
uvicorn app.main:app --reload
```

Then open `http://127.0.0.1:8000/docs` and try `/movies/assist`.

Each request sends your text to Google's Gemini API twice: once to create the
embedding and once to write the answer. Google's terms for the free tier allow
it to use what you send to improve its products and to let human reviewers read
it, so only type requests you'd be happy for Google to see.

The setup page covers the database, token and loader:
[`docs/setup.md`](../../docs/setup.md).

## Data and licences

Film facts come from [Wikidata](https://www.wikidata.org), released under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). Plot text comes
from the [English Wikipedia](https://en.wikipedia.org), released under
[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). The endpoint
sends the first 300 characters of each plot to Gemini, and returns links to the
articles, not the plot text. The `cmovie_rating`, `cmovie_votes` and
`cmovie_popularity` columns are fictional numbers generated by the loader, not
real audience scores.
